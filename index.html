怎么读这张表：下载量高的三个（桌宠、表格、插件市场）是基础能力， 装的人最多也最不容易坏；中后段都是解决具体问题但有前提的插件 —— 比如管理面板， 装到第 20 个插件时你才需要它。
局限：下载量只说明有人在用，不说明好用；而且它会波动 （这张表抓取于 2026-10-26，同一插件不同月份能差好几倍）。 没有 npm 包的插件无法比较，不在这张表里。

怎么装这些插件

用官方文档给的 GitHub 直链在国内常常会卡在 fetch failed —— 那是超时，不是命令写错。换一个能直连的地址前缀即可：

dsh plugin --profile <你的profile> add https://ghproxy.net/https://github.com/OWNER/REPO/releases/download/vX.Y.Z/NAME-X.Y.Z.tgz

装完重启一次 dsh（插件是启动时组装的），然后在会话里直接让 agent 调用对应工具。
